# Client x Server: a sociedade entre as máquinas

## O que aprendi

- **Client (cliente):** quem pede (navegador, app, celular)
- **Server (servidor):** quem responde e processa o pedido
- As máquinas formam uma "sociedade": cada uma tem um papel e todas dependem umas das outras
- Uma mesma máquina pode ser cliente de uma e servidor de outra
- Na prática, um pedido passa por vários intermediários até chegar ao lugar onde é processado

## Analogia do restaurante

```
Cliente  →  Garçom  →  Cozinha
(pede)     (leva)      (prepara)

Navegador → Servidor web → Banco de dados / outros serviços
```

## Exemplo real

Ao abrir o devnews, o navegador (client) pede a página e a Vercel (server) devolve o HTML.

## Analogia

É um restaurante: o cliente não entra na cozinha, ele fala com o garçom, e o garçom fala com a cozinha.
