# Criar um repositório e conectar com a máquina

**Data:** 2026-10-06
**Aula:** curso.dev, aula 2

## O que aprendi
- `git clone` copia o repositório do GitHub para a minha máquina
- `git status` mostra se tem alterações pendentes
- `git remote -v` mostra para onde o `push` vai
- `git log --oneline` lista o histórico de commits

## Exemplo real
Clonei o `til-dev` via SSH e confirmei com `git remote -v`.

## Para lembrar
Commit guarda a "foto" localmente, push envia para o GitHub.
