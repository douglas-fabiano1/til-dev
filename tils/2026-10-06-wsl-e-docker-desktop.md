# WSL e Docker Desktop

## O que aprendi
- **WSL:** roda um Linux dentro do Windows
- **Docker Desktop:** roda containers (ambientes isolados e idênticos em qualquer máquina)
- Docker usa o WSL por baixo no Windows

## Por que importa
O projeto vai rodar igual na minha máquina e em produção.

## Analogia
Container é uma marmita lacrada: o conteúdo é o mesmo onde for aberta.
