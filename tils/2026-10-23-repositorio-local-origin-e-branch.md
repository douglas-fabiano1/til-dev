# Repositório local, origin e branch


## O que aprendi

- **Repositório local:** a cópia do projeto na minha máquina, onde eu trabalho
- **origin:** o apelido do repositório remoto no GitHub
- **branch:** uma linha de histórico; `main` é a principal
- `git remote -v` mostra a URL do origin
- `git branch` lista as branches (a atual vem com `*`)

## Comandos

```bash
git remote -v     # mostra para onde o push vai
git branch        # lista as branches
```

## Exemplo real

No devnews, `git remote -v` mostra `origin  git@github.com:douglas-fabiano1/devnews.git`.

## Analogia

O repositório local é o meu caderno. O origin é a cópia na nuvem. A branch é o caminho que a história do caderno segue.
