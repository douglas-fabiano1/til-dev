# Instalar o Ubuntu no WSL

**Data:** 2026-10-07
**Aula:** curso.dev, aula 3

## O que aprendi
- O Ubuntu roda dentro do Windows via WSL
- Na primeira execução, ele pede usuário e senha do Linux
- Posso abrir o terminal Ubuntu direto do menu Iniciar

## Analogia
O WSL é um apartamento Linux dentro da casa Windows.
