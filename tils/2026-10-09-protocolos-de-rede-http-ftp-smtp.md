# Protocolos de rede: HTTP, FTP e SMTP

**Data:** 2026-10-09
**Aula:** curso.dev, aula 4

## O que aprendi
- Protocolo é um conjunto de regras para dois computadores conversarem
- **HTTP:** páginas web e APIs (navegador ↔ servidor)
- **FTP:** transferência de arquivos
- **SMTP:** envio de e-mails

## Por que importa
O devnews vai usar HTTP para servir páginas e SMTP para enviar o e-mail de ativação.

## Analogia
Cada protocolo é um tipo de serviço dos correios: carta comum (HTTP), encomenda de arquivos (FTP), serviço de e-mail (SMTP).
