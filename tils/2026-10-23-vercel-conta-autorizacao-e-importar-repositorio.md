# Vercel: criar conta, autorizar o GitHub e importar o repositório

## O que aprendi

- Criei a conta na Vercel entrando com o GitHub
- Autorizei a Vercel a acessar o meu projeto no GitHub
- Importei o repositório git do devnews
- A Vercel detectou o Next.js sozinha e fez o primeiro deploy
- A partir daí, cada `git push` gera um novo deploy

## Passo a passo

1. Acessar vercel.com e entrar com o GitHub
2. Autorizar o acesso, escolhendo só os repositórios necessários
3. Add New → Project
4. Importar o repositório `devnews`
5. Deploy

## Cuidado ao autorizar

Dar acesso apenas ao repositório que a Vercel vai usar, e não a todos (princípio do privilégio mínimo).

## Analogia

É entregar à gráfica a chave de uma única gaveta, não do escritório inteiro.
