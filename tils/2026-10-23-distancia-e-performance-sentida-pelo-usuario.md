# Distância entre client, server e a performance sentida

## O que aprendi

- Quanto maior a distância entre cliente, garçom (servidor) e cozinha (banco/serviços), mais tempo cada pedido leva
- Quem sente isso é o usuário final, como lentidão ao abrir uma página
- O que importa é a performance **sentida**, não só a velocidade do código
- Servidor perto do usuário tende a responder mais rápido
- Cada ida e volta entre as partes soma tempo

## Analogia do restaurante

```
Cozinha longe do salão  → garçom caminha mais → prato demora a chegar
Cozinha ao lado         → prato chega rápido
```

## Para lembrar

Ao escolher onde hospedar o site e o banco de dados, pensar em onde estão os usuários e manter as partes próximas entre si.

## Analogia

Se o garçom precisa atravessar a cidade para buscar cada prato, o cliente sente a demora, mesmo que a cozinha seja excelente.
